# 🚀 Internet Speed Checker (Python CLI)

A lightweight interactive command-line utility (`internet_speed_checker.py`) written in **Python** using the `speedtest-cli` library to measure network **Download Speed**, **Upload Speed**, and **Ping Latency**.

---

## 📂 Repository Structure

- `internet_speed_checker.py`: Interactive CLI menu script for testing network performance.
- `README.md`: Project documentation.

---

## ✨ Features

Interactive numbered prompt allowing you to test:
1. **Download Speed** (`st.download()`)
2. **Upload Speed** (`st.upload()`)
3. **Ping Latency** (`st.results.ping` against the nearest Speedtest server)

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparsh0106/Internet-Speed-Checker.git
   cd Internet-Speed-Checker
   ```

2. **Install dependencies**:
   ```bash
   pip install speedtest-cli
   ```

3. **Run the utility**:
   ```bash
   python internet_speed_checker.py
   ```
